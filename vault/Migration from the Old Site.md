# Migration from the Old Site

`pokemontxk.com` was a hand-maintained static site. Every change meant editing a JavaScript file
and redeploying.

| File | Held | Pain |
|---|---|---|
| `markers.js` (24 KB) | 113 POIs as a literal JS array | Regenerated by hand from a KMZ |
| `meetup.js` | 5 hard-coded strings | Edited **weekly** |
| `script.js` (56 KB) | Map logic, raid route, hotspot polygon | Coordinates pasted inline |

Leaflet from unpkg, CARTO tiles, no build step, no backend.

## What the data actually turned out to be

Three findings changed how the import was written. Each was only visible by looking.

### `ambassador-popup.png` is an icon, not a photo

24 markers reference it. All 24 are named `Campsite - *`, and nothing else uses it. It is the
ambassador star marking Campsite locations — so it drives `is_campsite` and is **not** imported
as media.

This takes the real photo count from the 96 that "has an image" suggests down to **63**
(96 − 24 icons − 9 community photos).

### Names are not unique

"Walk Through History" appears four times across two types. "Powerspot" four times. Slugs
therefore need deterministic disambiguation against a stable sort, so repeated imports assign
identical slugs rather than shuffling them.

### The file was **not** encoding-corrupted

Early research reported mojibake (`Pok<?>mon`) and the plan called for a re-decoding step. That
was wrong — it was a Windows console rendering artifact. Strict UTF-8 decode passes with zero
U+FFFD and no BOM.

> [!tip] The lesson
> The "fix" would have been pointless at best and corrupting at worst. Checking the raw bytes
> took one command. Verify the defect exists before writing code to fix it.

## Type mapping

| Old | New |
|---|---|
| `pokestop` / `gym` / `powerspot` | unchanged |
| `specialgym` | `gym` + `is_meetup_spot` — keeps `type` a clean three-value enum |
| `communityphoto` | a `media` row pinned to the map, **not** a POI |

Filenames were URL-encoded (`MainCourseHole%238.jpg`, `LetsWorkOut!.jpg`) and are normalised to
safe R2 keys.

## What was deliberately preserved

- The campsite / ambassador framing
- Raid route and hotspot polygon, now GeoJSON in `map_shapes` rather than inline in `script.js`
- Photo credits, source titles, dates and article links — see [[Attribution Obligations]]
- The fair-use disclaimer
- Discord, Facebook, Instagram and Campfire links
- The Code of Conduct, now also readable HTML at `/conduct`

## One correction made to their content

The old `meetup.js` labelled an August meetup "CST". August is CDT. The new system derives the
label from the zone rather than trusting a typed one — see `src/lib/time.ts`.
